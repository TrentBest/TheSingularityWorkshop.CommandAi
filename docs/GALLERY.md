# CommandAi gallery

CommandAi is currently demonstrated by a small source-authored console example. It prints a versioned proposal envelope, decodes it, and makes the no-execution boundary visible. The example's local representation and round-trip path was verified by GitHub Actions at commit [`63dad94`](https://github.com/TrentBest/TheSingularityWorkshop.CommandAi/commit/63dad94c2d2feaf6344fdd6e3f180bfbbf8446de). It does not prove authorization, vocabulary resolution, model correctness, live-provider behavior, or safe execution.

- [Quickstart source](../examples/CommandAi.QuickStart/Program.cs) — reproduce with the command in [Usage](USAGE.md).
- [Wire format and design rationale](THEORY.md) — understand the protocol and its limits.
