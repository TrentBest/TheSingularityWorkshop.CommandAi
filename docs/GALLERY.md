# CommandAi gallery

CommandAi is currently demonstrated by a small source-authored console example. It prints a versioned proposal envelope, decodes it, and makes the no-execution boundary visible. The example demonstrates representation and round-trip behavior only; it does not prove authorization, vocabulary resolution, model correctness, or safe execution.

- [Quickstart source](../examples/CommandAi.QuickStart/Program.cs) — reproduce with the command in [Usage](USAGE.md).
- [Wire format and design rationale](THEORY.md) — understand the protocol and its limits.
