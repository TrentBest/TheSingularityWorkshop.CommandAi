The boundary is the product

CommandAi describes what an application chooses to expose and how a proposed response is represented. It does not own application memory, domain meaning, policy, authorization, or execution.

Three connected ideas

01 · Proposals

Ordered atomic actions can be represented in a compact form or an enriched form with explicit identity, target, scope, preconditions, idempotency identity, and expected outcome.

02 · Address spaces

Applications declare readable context slots and writable response slots. Exchanges carry typed values and correlate requests with responses.

03 · Wire contracts

Versioned codecs enforce structural bounds and correlation. A successful parse establishes shape—not trust, correctness, or permission to act.

Trust remains outside the model

CommandAi can

Validate declared addresses, direction, required slots, value kinds, response correlation, and representation structure.

The host must

Resolve trusted identities, evaluate current state and domain rules, authorize, request human approval where required, and dispatch accepted operations.

Design invariant: structured data is not authority. Never treat a decoded proposal as an instruction to execute.
