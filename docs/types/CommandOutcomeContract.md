# CommandOutcomeContract

An immutable expected-outcome declaration containing an opaque OutcomeId and a bounded collection of uniquely identified CommandOutcomeField declarations. It describes the shape expected from a conforming result; it is not an actual outcome or CI verdict.

Source: [CommandOutcomeContract.cs](../../CommandOutcomeContract.cs).

Actual correlated outcomes belong to ProtocolAi and the host runtime. CI evidence and verdicts belong to CiAi.
