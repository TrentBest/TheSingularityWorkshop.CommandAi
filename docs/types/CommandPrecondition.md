# CommandPrecondition

A bounded immutable pair of GrammarVersion and Expression. CommandAi transports this opaque condition; GrammarAi owns its grammar and the host evaluates it against live state. The constructor rejects empty values and enforces source-defined size limits.

Source: [CommandPrecondition.cs](../../CommandPrecondition.cs).

A precondition is not a truth claim, authorization decision, or execution receipt. See [Theory](../THEORY.md) and [Architecture](../ARCHITECTURE.md).
